# NetworkWalks Cybersecurity Internship - Week 2

## Overview
This repository contains the completed practical tasks and final penetration testing report for Week 2 of the Cybersecurity & Ethical Hacking program at NetworkWalks.

## Contents
- **W2-PM1-Footprinting:** Scan logs and screenshots gathered using `whois`, `whatweb`, `nslookup`, `curl`, `wafw00f`, and `dnsrecon` on Kali Linux.
- **W2-PM5-Zenmap-scanning:** Local LAN discovery results, live host details, and the exported `Topology_Map.pdf` using Zenmap.
- **Final Report:** Complete documentation covering methodology, risk analysis, security recommendations, and visual evidence.
